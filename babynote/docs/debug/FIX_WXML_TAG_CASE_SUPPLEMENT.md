```
[WXML 文件编译错误] ./pages/index/index.wxml

  146 |         <view class="option-label">已添加的营养品</view>
      |                                                  ^
```

## WXML 标签规范重申

### 必须小写的标签
微信小程序严格要求所有原生标签使用小写：

```xml
<!-- ✅ 正确示例 -->
<view></view>
<text></text>
<image></image>
<button></button>
<input/>
<slider></slider>

<!-- ❌ 错误示例（会导致编译失败） -->
<View></view>
<Text></Text>
<Button></Button>
```

### 为什么必须小写？
1. **解析器要求**：微信小程序的 WXML 解析器是大小写敏感的
2. **性能优化**：统一小写可以简化解析逻辑
3. **规范统一**：与 HTML5 的最佳实践一致

## 如何避免再次发生

### 方法 1：编辑器配置
在 VSCode 或其他编辑器中配置 WXML 语法高亮和自动检查

### 方法 2：使用查找替换
快速检查并替换所有大写标签：
```bash
# 查找所有大写闭合标签
grep -n "</[A-Z]" pages/index/index.wxml
```

### 方法 3：代码审查
在提交代码前，使用工具自动检查大小写
