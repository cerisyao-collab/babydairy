# 首页界面重构 - 简洁交互 🎯

## 设计目标

**更简洁、更直观的喂奶记录体验**

### 核心改进

1. **删除换尿布功能**（移至护理页面）

```javascript
// 记录母乳（直接保存）
async recordBreast() {
  wx.showLoading({ title: '记录中...' })
  
  try {
    // 获取用户信息
    let userId = 'anonymous'
    let userName = '匿名'
    
    if (this.data.userInfo) {
      userId = this.data.userInfo.nickName
      userName = this.data.userInfo.nickName
    } else {
      const systemInfo = wx.getSystemInfoSync()
      userId = 'anon_' + systemInfo.brand + '_' + systemInfo.model
    }

    const recordData = {
      type: 'feeding_breast',
      user_id: userId,
      user_name: userName,
      detail: '母乳'
    }

    await supabase.insert('records', recordData)
    
    wx.hideLoading()
    wx.showToast({
      title: '母乳喂养记录成功',
      icon: 'success'
    })

    this.loadRecords()
  } catch (err) {
    wx.hideLoading()
    wx.showToast({
      title: err.message || '记录失败',
      icon: 'none'
    })
  }
},

// 打开奶粉弹窗
openFormulaModal() {
  this.setData({
    formulaAmount: 150,
    showFeedingModal: true
  }, () => {
    console.log('奶粉弹窗已打开')
  })
}
```

## 为什么删除换尿布功能？

### 原因分析

1. **功能定位清晰**：
   - 首页：专注高频的喂奶记录
   - 护理页：包含洗澡、换衣、剪指甲等全面护理
   - 换尿布属于护理范畴

2. **减少认知负担**：
   - 首页按钮越少，操作越快
   - 避免新手父母手忙脚乱

3. **数据分离**：
   - 喂奶是最高频的功能（每天 8-12 次）
   - 换尿布相对低频（每天 6-8 次）
   - 分开记录更清晰

### 换尿布功能在哪里？

**位置**：护理页面（pages/care/care）

**操作**：
1. 点击底部 TabBar "🛁 护理"
2. 使用 "💩 排便" 按钮记录换尿布

**未来优化**：可以在护理页面增加更详细的排便记录选项

## 常见问题

### Q1: 为什么不显示统计数据了？
**A**: 为了界面简洁，我们删除了"今日统计"模块。如果需要，可以在"记录"页面查看完整统计。

### Q2: 换尿布功能完全删除了吗？
**A**: 不是的！换尿布功能移到了"护理"页面，仍然可以使用。这样首页更专注，护理页面更全面。

### Q3: 能不能把母乳和奶粉合并成一个按钮？
**A**: 不建议。分开两个按钮可以让操作更快速，特别是半夜喂奶时，单手就能完成记录。

### Q4: 奶粉的默认奶量是多少？
**A**: 150ml。每次打开弹窗都会重置为这个值，可以根据宝宝实际情况调整。

### Q5: 滑动条最小是 50ml，宝宝喝不了这么多怎么办？
**A**: 可以联系开发者调整最小值。目前设计是基于大多数宝宝的食量。
