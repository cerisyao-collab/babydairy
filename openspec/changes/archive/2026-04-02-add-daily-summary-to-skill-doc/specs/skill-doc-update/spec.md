## ADDED Requirements

### Requirement: 技能文档必须包含每日总结功能说明

技能文档必须添加 `daily_summary` 函数的说明，包括参数、返回值和使用示例。

#### Scenario: 文档中包含 daily_summary 函数说明
- **WHEN** 用户阅读技能文档
- **THEN** 可以找到 `daily_summary` 函数的参数说明、返回值和使用示例

### Requirement: 技能文档必须包含生长标准数据说明

技能文档必须说明生长标准数据的来源（崔玉涛建议和浙江省妇保标准）和适用范围（0-12 个月婴儿）。

#### Scenario: 文档中包含标准值数据来源说明
- **WHEN** 用户阅读技能文档
- **THEN** 可以了解生长标准数据的来源和适用范围

### Requirement: 技能文档必须明确数据存储结构

技能文档必须明确说明数据按月归档（`YYYY-MM.json`），但支持按日查询和总结。

#### Scenario: 文档中明确存储结构
- **WHEN** 用户阅读技能文档
- **THEN** 可以理解数据存储按月归档，但支持按日查询
