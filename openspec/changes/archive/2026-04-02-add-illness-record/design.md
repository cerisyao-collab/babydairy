## Context

当前 baby-diary 技能支持 7 种记录类型（喂奶、大小便、营养品、洗澡、睡眠、生长指标），但缺少病情记录功能。父母需要记录宝宝的疾病症状、就医情况等信息。

## Goals / Non-Goals

**Goals:**
- 新增 illness 记录类型，支持记录病情相关信息
- 字段设计灵活，适应各种疾病场景
- 与其他记录类型一样支持创建、查询、更新、删除
- 支持图片附件（如皮疹照片、医疗报告等）

**Non-Goals:**
- 不提供医疗诊断建议
- 不与医院系统对接
- 不替代专业医疗记录

## Decisions

### 1. 病情记录字段设计
**Decision:** 采用灵活字段设计，核心字段 + 可选备注

**字段:**
- `symptom`: 症状描述（必填）
- `cause`: 可能病因（可选）
- `diagnosis`: 医生诊断（可选）
- `treatment`: 治疗方案（可选）
- `severity`: 严重程度（轻/中/重）
- `temperature`: 体温（可选）
- `hospital_visit`: 是否就医（布尔）
- `notes`: 其他备注（可选）

**Rationale:**
- 覆盖常见病情记录需求
- 灵活设计适应不同场景
- 必填字段最少化，降低使用门槛

### 2. 记录类型标识
**Decision:** 使用 `illness` 作为记录类型标识

**Rationale:**
- 语义清晰，易于理解
- 与现有记录类型命名一致

## Risks / Trade-offs

**Risk:** 用户可能误解为医疗建议
→ **Mitigation:** 在文档中明确说明仅用于记录，不提供诊断

**Risk:** 字段不够灵活，无法满足特殊需求
→ **Mitigation:** 提供 `notes` 字段作为补充

**Trade-off:** 字段数量 vs 易用性
→ 选择平衡方案：核心字段 + 灵活备注
