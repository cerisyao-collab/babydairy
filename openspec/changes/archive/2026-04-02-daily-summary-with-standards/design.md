## Context

当前宝宝日记系统已实现记录创建、查询和重复检测功能，但缺少数据分析和总结能力。父母需要手动判断宝宝的生长发育是否正常，无法快速获得专业建议。

**现状**：
- 记录按日存储在 JSON 文件中
- 包含喂奶、大小便、生长指标等数据类型
- 无数据分析和对比功能

**需求**：
- 内置权威标准值（崔玉涛建议 + 浙江省妇保标准）
- 自动计算出生天数
- 对比实际数据与标准值
- 输出差异分析和建议

## Goals / Non-Goals

**Goals:**
- 实现标准值数据本地化，无需联网查询
- 支持 0-12 个月婴儿的各项指标对比
- 自动生成每日近况总结
- 输出差异分析和育儿建议

**Non-Goals:**
- 不提供医疗诊断，仅提供参考建议
- 不支持自定义标准值（使用权威标准）
- 不分析历史趋势（仅当日对比）

## Decisions

### 1. 标准值数据结构

**决策**: 使用 JSON 文件存储标准值，按出生天数索引

**理由**:
- 与现有记录存储格式一致
- 易于查询和更新
- 可离线访问

**实现**:
```json
{
  "standards": {
    "day_1": {
      "weight_kg": {"min": 2.5, "max": 4.0, "avg": 3.2},
      "height_cm": {"min": 47, "max": 53, "avg": 50},
      "urine_count": {"min": 4, "max": 8},
      "bowel_count": {"min": 1, "max": 4},
      "feeding_times": {"min": 8, "max": 12}
    },
    ...
  }
}
```

### 2. 标准值来源

**决策**: 综合崔玉涛建议和浙江省妇保标准，取合理范围

**理由**:
- 崔玉涛：国内权威儿科专家，建议实用性强
- 浙江省妇保：三甲专科医院标准，数据科学
- 综合两者，确保标准可靠

**指标范围**：
- 体重、身高：按 WHO 生长曲线中国标准
- 排尿次数：0-3 月 6-8 次/天，4-6 月 4-6 次/天
- 大便次数：母乳喂养 2-5 次/天，配方奶 1-3 次/天
- 喂养次数：新生儿 8-12 次/天，3 月后 6-8 次/天

### 3. 对比分析逻辑

**决策**: 三分区判断（偏低/正常/偏高）

**理由**:
- 简单直观，易于理解
- 避免过度医疗化
- 给出明确建议

**实现**:
```python
if value < standard["min"]:
    status = "偏低"
    advice = "请关注，必要时咨询医生"
elif value > standard["max"]:
    status = "偏高"
    advice = "请关注，必要时咨询医生"
else:
    status = "正常"
    advice = "发育良好，继续保持"
```

### 4. 总结输出格式

**决策**: 结构化文本输出，包含：
- 当日概况（记录总数、数据类型）
- 生长指标对比
- 喂养情况对比
- 排泄情况对比
- 综合建议

**理由**:
- 信息完整，一目了然
- 便于用户理解和分享

## Risks / Trade-offs

**[标准值个体差异] →** 每个宝宝发育节奏不同
- *缓解*: 强调标准值仅供参考，个体差异正常
- *缓解*: 建议持续观察而非单次判断

**[数据来源局限] →** 标准值可能不适用于所有地区
- *缓解*: 标注数据来源，用户可自行判断适用性
- *缓解*: 保留更新标准值的灵活性

**[过度解读风险] →** 家长可能对数据过度焦虑
- *缓解*: 输出措辞温和，避免制造焦虑
- *缓解*: 强调"参考范围"而非"标准答案"
